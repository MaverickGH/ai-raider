## Prerequisites

- Docker (running)
- An LLM API key from any [supported provider](/llm-providers/overview) (OpenAI, Anthropic, Google, etc.)

## Installation

<Tabs>
  <Tab title="curl">
    ```bash
    git clone https://github.com/MaverickGH/ai-raider && cd ai-raider && uv pip install -e .
    ```
  </Tab>
  <Tab title="pipx">
    ```bash
    pipx install airaider-agent
    ```
  </Tab>
</Tabs>

## Configuration

Set your LLM provider:

```bash
export AIRAIDER_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
```

<Tip>
For best results, use `openrouter/z-ai/glm-5.3` (the default pick), `openai/gpt-5.4`, `anthropic/claude-opus-4-6`, or `openai/gpt-5.2`.
</Tip>

## Run Your First Scan

```bash
airaider --target ./your-app
```

<Note>
First run pulls the Docker sandbox image automatically. Results are saved to `airaider_runs/<run-name>`.
</Note>

## Target Types

AiRaider accepts multiple target types:

```bash
# Local codebase
airaider --target ./app-directory

# GitHub repository
airaider --target https://github.com/org/repo

# Live web application
airaider --target https://your-app.com

# Multiple targets (white-box testing)
airaider -t https://github.com/org/repo -t https://your-app.com

# Targets from a file, one target per non-empty, non-comment line
airaider --target-list ./targets.txt
```
