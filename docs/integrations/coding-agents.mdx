AiRaider is built to be driven by AI coding agents. Install the official agent skills and your agent knows how to run pentests, remediate findings, and wire AiRaider into CI.

## Install the Skills

Works with any agent that supports the open [SKILL.md standard](https://agentskills.io) — Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and dozens more:

```bash
npx skills add usestrix/strix
```

| Skill | What your agent learns |
|-------|------------------------|
| `penetration-testing-with-airaider` | Run headless scans against code, URLs, domains, or IPs with budget caps, and read the results |
| `fix-security-vulnerabilities-with-airaider` | Triage findings, fix root causes, and re-run AiRaider to verify each fix |
| `ci-security-scanning-with-airaider` | Add PR security scanning to GitHub Actions or any CI (self-hosted CLI in your runner) |
| `application-security-testing` | Assess a whole product: choose the right test for each asset, then rank the findings into one remediation plan |
| `web-app-penetration-testing` | Black-box pentest of a live web app or staging site — scope, credentials, and multi-account access-control testing |
| `api-security-testing` | Test a REST/GraphQL API against the OWASP API Security Top 10 — schema-driven enumeration, BOLA/IDOR, authz |
| `owasp-top-10-testing` | Systematic OWASP Top 10 assessment with honest per-category coverage |
| `find-security-vulnerabilities-in-code` | White-box security review of a repo or working tree, with exploits to confirm findings |

Install a single skill with `npx skills add usestrix/strix --skill penetration-testing-with-airaider`, or use one without installing:

```bash
npx skills use usestrix/strix@penetration-testing-with-airaider | claude
```

## Running scans

AiRaider runs self-hosted: the open-source CLI runs locally in a Docker sandbox with your own LLM key. Free, fully local, air-gap capable, and agent-friendly — headless with exit codes and structured output.

## Agent-Friendly Interfaces

Everything an agent needs is machine-readable:

- **Headless CLI** — `airaider -n` runs without the TUI and exits with `0` (clean), `1` (error), or `2` (vulnerabilities found).
- **Structured results** — every run writes `vulnerabilities.json`, `vulnerabilities.csv`, `findings.sarif` (SARIF 2.1.0), and per-finding Markdown under `airaider_runs/<run-name>/`.
- **Budget controls** — `--max-budget` and `--max-turns` give agents hard cost/time caps.
- **`AGENTS.md`** — the [repository's agent guide](https://github.com/MaverickGH/ai-raider/blob/main/AGENTS.md) with a quick reference.
